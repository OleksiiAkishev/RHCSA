# NAT (Network Addres Translation)
The private IP addresses cannot easily talk to the external world, the same the external world cannot reach private IP adddresses. Thus the NAT is used at the router level, in that case the IP address is replaced with the IP address of NAT router. And the nodes in the Internet they think they communicate with the NAT router and not with indivudual hosts. 

# CIDR (Classless Inter-Domain Routing)
Tells which bits from IP address belong to host. 

CIDR notation: /24
classic notation: 255.255.255.0 

# MAC address
Each physical network card has the 12 byte MAC address and uses it in the local network(LAN or WLAN).Just up to the first router that is encountered and they cannot be used between nodes which are on the different networks.
MAC example: 00:0c:29:7d:9b:17; first 6 bytes are vendor ID, and the other 6 bytes a node ID.

# Addresses and Interfaces
- Fixed IP addresses:
    for servers that always need to be available at the same IP address
- Dynamic assigned IP addresses
    for users devices and for cloud environment. Usually a DHCP (Dynamic Host Configuration Protocol) is used. 

Linux had the names for the network cards: eth0, eth1, eth2, etc. Where the the naming is assigned based on the order detection of the network card. So the eth0 is the first card and so on.

After RHEL 7:
- en Ethernet
- wl WLAN
- ww WWAN
- o onboard
- s hotplug slot
- p PCI location
- x device name based on the MAC address of the network card
- number followed for ID, port, index

Ex: eno16777734

# Validating Network Address Configuration

- configure and monitor network addresses
    ip addr
- configure and monitor routing information
    ip route
- configure and monitor link state
    ip link
- check list of all UDP and TCP ports that are listening on your server
    ss -tul

# Managing Network COnfiguration with nmtui and nmcli

nmtui - UI tool and recommended for exam
nmcli - pure terminal tool

- When the RHEL server is up the NetworkManager reads the network card configurations which are under /etc/NetworkManager/system-connections .
    - a device is a a network interface card
    - a connection is the configuration that is used on a device
- Check current permissions for the network change:
    nmcli general permissions
- Check current conenction status
    nmcli con show


# Setting up hostname and name resolution

FQDN (Fully qualified domain name): a complete DNS hostname that contains the name of the host (myserver) as well as the DNS domain it is used in (example.com), giving the FQDN myserver.example.com

- Hostname status check
  hostnamectl status
